# Changelog

## 0.1.0 - 2026-11-16

Prima release pubblica di Aethersy Research.

- Porting brandizzato Aethersy.AI di
  [hyperresearch](https://github.com/jordan-gibbs/hyperresearch) di Jordan Gibbs.
- Pacchetto Python rinominato in `aethersy_research`.
- CLI rinominata in `aethersy-research`, con alias `ares`.
- Skill rinominata in `aethersy-deep-research` e descrizione orientata a Lara.
- Metadati di plugin, marketplace, repository e documentazione aggiornati per
  Aethersy.AI.
- Pipeline, server MCP, provider e comportamento del vault mantenuti.

L'opera originale e la sua licenza MIT sono attribuite in `NOTICE.md` e
`LICENSE`.
